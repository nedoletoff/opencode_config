# Навык: Git Release

## Шаги выполнения
1. Переключись на главную ветку: `git checkout main` и выполни `git pull`.
2. Обнови файл `CHANGELOG.md`, добавив новую версию и дату.
3. Закоммить изменения с сообщением на русском языке: `chore(release): подготовка vX.Y.Z`.
4. Создай аннотированный тег: `git tag -a vX.Y.Z -m "Релиз vX.Y.Z"`.
5. Запушь коммит и тег: `git push origin main --tags`.
